# Output format

Default output:

1. The polished text as plain prose, not in a code block.
2. Add `Revision notes:` only for material structural or stylistic choices the user needs to understand, or when requested. Scale their length to the change; a short polish may need no notes.
3. If the rewrite changed section logic, explain the material change briefly. Follow an explicit prose-only request; unresolved factual gaps still need clear markers.

If the user asks for side-by-side revision, provide:

- `Original`
- `Polished`
- `Why changed`

If any paragraph's structural problem could not be fixed without inventing content, say so under `Revision notes:` instead of papering over it.

For substantive main-text restructuring or compression, add a compact
`Main-text discipline audit:` that identifies material kept, replaced,
compressed, relocated to SI/caption, or deleted; states which descriptive and
primary inferential quantities remain in the main text; and reports the
before/after word count. Do not bury the polished prose under the audit.
For a short passage, include only material evidence-placement changes or gaps; do not require a separate audit block. Follow the user's requested output format.
