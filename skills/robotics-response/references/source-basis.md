# Source basis

Use this file to keep `robotics-response` grounded in primary or near-primary publication
process sources. Source labels distinguish binding venue or platform rules from general editorial
advice.

## Source hierarchy

1. Current official target venue, track, year, and submission-platform instructions.
2. The editor decision letter, conference reviews, or chair instructions supplied by the user.
3. Inspectable manuscript, revision, analysis, figure, table, or experiment artifacts supplied by
   the author.
4. General publisher or community guidance, used only when it does not conflict with the first
   three sources.

If current official instructions conflict with this file, follow the current official
instructions. Never reuse a previous venue edition's rebuttal budget or permissions from memory.

relevant Nature or Springer Nature journal, or when the user explicitly requests this publisher's
editorial advice. It does not define conference rebuttal rules.

## Journal-route implementation implications

- Point-by-point response is the default structure for journal revision cases.
- Every referee criticism must be answered, justified, or flagged as unresolved. Cross-references are allowed only within the same reviewer's own response, never across mutually blind reviewers.
- A cover letter is adjacent revision-package material: draft it when the user asks for a cover letter or a complete revision package, but do not duplicate the full point-by-point response inside it.
- The skill should copy or preserve reviewer wording supplied by the user unless the user asks for anonymization or summarization.
- Tone, accuracy, and traceability should meet the standard of material that may later be reviewed by editors, reviewers, or public readers.
- Do not overstate source authority: Springer Nature advice is useful writing guidance, not journal-specific binding policy.

For `conference-rebuttal`, use `conference-rebuttal.md` and the current official venue/platform
instructions instead of deriving deliverables or permissions from this table.
